🖨️ CAMPUS-PRINT
Skip the Queue – Print Smart on Campus

CAMPUS-PRINT is a web-based platform that allows students to upload documents and place print requests online, helping them avoid long queues at campus printing shops.
Students can upload files, select print options, and pick them up directly from the print center.

🚀 Features

📂 Upload documents for printing

🖨️ Select printing preferences (pages, copies, etc.)

⏳ Skip long queues at campus print shops

📍 View print shop location using Google Maps

📱 Clean and responsive UI for students

⚡ Fast and simple ordering system

⚙️ Installation & Setup

1️⃣ Clone the repository

git clone https://github.com/yourusername/CAMPUS-PRINT.git

2️⃣ Go to the project directory

cd CAMPUS-PRINT

3️⃣ Install dependencies

npm install

4️⃣ Run the server

node server.js

5️⃣ Open in browser

http://localhost:3000
💡 How It Works

Student uploads the document

Selects printing options

Request is sent to the print shop

Student picks up the printed document without waiting in line
